# pollyroll

Lightweight, zero-dependency 3D dice for the web. WebGL2 renderer, deterministic custom physics,
and result-first rolls built for multiplayer.

> Status: under construction. Usage documentation lands with 0.1.0.

## Entry points

| Import             | Contents                                            |
| ------------------ | --------------------------------------------------- |
| `pollyroll`        | Notation parser, roll events, evaluation (DOM-free) |
| `pollyroll/render` | WebGL2 dice tray                                    |
| `pollyroll/react`  | React hook and overlay component                    |
